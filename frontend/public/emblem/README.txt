STATE EMBLEM OF INDIA  (Lion Capital of Ashoka)
================================================

This folder is where the OFFICIAL emblem file goes.

  1. Download the official emblem from the Government of India's
     official source (search "emblem.india.gov.in" / "Digital India
     Web Guidelines - State Emblem of India"). Do not trace, redraw or
     copy it from a random website.
  2. Save it here as:   emblem.svg
  3. In src/app/config/site.config.ts set  useEmblemImage: true  and restart "npm start".
     (Until then the header shows the Ashoka Chakra.)

IMPORTANT - LEGAL
-----------------
Use of the State Emblem is regulated by the State Emblem of India
(Prohibition of Improper Use) Act, 2005. It may be used only by
authorised Government bodies, and only as per the prescribed rules.
If you are NOT an authorised Government organisation (for example a
college / final-year project), do NOT use the emblem or "Government
of India" branding; edit src/app/config/site.config.ts and use your
own organisation name instead.
